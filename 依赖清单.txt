五、两个要注意的地方
================================================================

1. allure-pytest 只是 pytest 的插件，只负责生成原始结果文件（allure-results）。
   要看 HTML 报告，还得单独装 allure 命令行工具（它是 Java 写的，不在 pip 里）。
   GitHub Actions 的 .github/workflows/test.yml 里如果没装它，
   「生成报告」那一步一定是红的——这也是当前 Actions 跑不通的原因之一。

2. 版本号里能看到 Python 3.14 比较新，个别老包（比如某些老版本 pymysql 分支）
   在 3.14 上可能装得上但跑不通。当前这套已验证 import 正常、pytest 能收集用例。
